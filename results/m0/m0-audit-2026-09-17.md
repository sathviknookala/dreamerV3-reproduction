# M0 completion audit — 2026-09-17

Maps every M0 requirement to where it is discharged, what evidence supports it, what verification was
actually performed, and any permitted deferral.

**Status vocabulary** ([spec.md §11](../../docs/spec.md)) — three independent axes:

| | Meaning |
|---|---|
| `specified` | Decided against a pinned source, written down with its rationale. |
| `implemented` | Code exists that realizes the specification. |
| `validated` | The milestone gate passed with a committed artifact. |

> **Everything below is `specified` only. Nothing in this repository is `implemented`. Nothing is
> `validated`.** There is no model code, no test, and no measurement. A completed specification is
> not a working mechanism, and this audit does not claim otherwise.

## F. Honest limits of this audit

- **It audits a document, not a system.** Every row says a decision is written down and sourced. None
  says anything runs.
- **Source tracing was performed against the pinned commit by reading code, not by executing it.**
  No JAX runtime was installed and no reference training run was performed. Numerical claims about
  the reference are read from source, not observed.
- **The derived parameter count is arithmetic over the spec.** Its agreement with an independent
  enumeration shows the shape table is self-consistent. It is not a measurement and does not
  validate any implementation.
- The `bfloat16`-vs-`float32` divergence is deliberately unquantified; this project starts in float32
  and precision is revisited only after correctness.
